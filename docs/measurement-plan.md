# Measurement plan

Track Search Console impressions, clicks, average position, indexed pages, duplicate-canonical reports, and query-to-page fit. Track privacy-preserving on-site events for finder completion, phone-link use, correction submissions, article depth, and internal-link use without recording search text or precise location.

For ads, measure eligible page views, consent rate, viewability, revenue per thousand eligible views, layout shift, interaction-to-next-paint, bounce rate, and finder exits. Compare by page class. Revenue experiments must keep help-route exclusions fixed and stop if Core Web Vitals, return visits, or navigation safety regress materially.
